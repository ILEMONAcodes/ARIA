# Nigerian public policy source snapshots

Eight original PDFs from the Nigerian National Information Technology Development
Agency (NITDA), downloaded through its [official regulatory catalogue](https://nitda.gov.ng/regulations/).
The user explicitly requested Nigerian sources. No U.S. policies are included.
These are public administrative/regulatory source snapshots for retrieval tests,
not a statement that every included instrument is current or applicable to an office.

| File | Document/version information verified in the source |
|---|---|
| `ng-domain-management.pdf` | .gov.ng and .mil.ng Domain Management Policy; version 2.0, May 2019 |
| `ng-government-websites.pdf` | Standards and Guidelines for Government Websites; catalogue identifies V3 |
| `ng-public-social-media.pdf` | Framework and Guidelines for the Use of Social Media Platforms in Public Institutions; 2019 |
| `ng-ict-service-providers.pdf` | Guidelines for Registration of ICT Service Providers/Contractors for Delivery of IT Services to MDAs |
| `ng-interoperability.pdf` | Nigeria e-Government Interoperability Framework; v1.2; July/August 2019 labels differ within the PDF |
| `ng-data-protection.pdf` | Nigeria Data Protection Regulation 2019 |
| `ng-cloud-technical.pdf` | National Cloud Technical Guideline 2026; approval 4 August 2026, effective 1 January 2027 (PDF page 2) |
| `ng-platform-code.pdf` | Code of Practice for Interactive Computer Service Platforms/Internet Intermediaries; catalogue/download title identifies 2022 |

`manifest.json` supplies display metadata; `provenance.json` records exact source
URLs, SHA-256, byte counts, retrieval date, date caveats and rights basis. Where a
complete issue date/circular number is not stated, those fields stay null. The
cloud approval/effective dates are preserved separately and are not relabelled as
an issue date. Upload-path dates are never substituted for issue dates.

Original bytes and publisher notices remain intact. The rights basis recorded
for the official administrative/regulatory text is section 3(b) of the
[Nigerian Copyright Act 2022 published by the Nigerian Copyright Commission](https://www.copyright.gov.ng/CopyrightAct/CopyrightAct2023FinalPublication1.pdf).
No government endorsement is implied. Source hashes prevent silent fixture changes;
CI and runtime do not download documents. Refreshing/replacing this corpus is an
explicit development task requiring source/evidence review.

The corpus is currently IT/governance focused. It is not a complete collection of
Nigerian HR, leave, travel or procurement rules. The separate `../policies/`
examples are fictional and must never be presented as Nigerian government policy.

# Golden question set

30 questions on the sample library: 20 the library answers, 10 it does not. Each has the expected answer points, the expected citation (document and page), or `"answerable": false` for correct "not found" behaviour. Scored by the eval script on three things: answer correct, citation correct, "not found" when it should be. Target 90% or higher.

Add questions to `golden_set.json`. Keep chunk size and passage count results in docs/DECISIONS.md.

# Audio fixtures

Short recorded utterances (16 kHz mono WAV) with a matching `.txt` file holding the expected transcript, plus a `manifest.json` listing the expected intent. Start with 20 to 30 sentences from Nigerian speakers covering names, office terms and numbers; grow to 100 to 200. Used for word error rate, speaker ID and e2e tests. WAV files are git-ignored by default; store them in Git LFS or a shared drive and note where in docs/DECISIONS.md.
